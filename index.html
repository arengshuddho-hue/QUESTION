🎓 CSE-57 Academic Portal

Welcome to the central academic repository for Batch 57, Section C. This portal is designed to streamline the sharing of resources, class routines, announcements, and important links in a secure and dynamic environment.

✨ Features

  • Firebase RTDB: Real-time syncing for notes and announcements.
  • Octoverse Theme: Deep dark UI matching GitHub's premium aesthetic.
  • Secure Admin: Protected dashboard to manage all portal data.
